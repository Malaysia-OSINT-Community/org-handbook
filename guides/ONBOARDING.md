# Onboarding Guide: Cyber-Hygiene in WhatsApp

This onboarding guide defines the minimum privacy baseline for all MOC members before active participation.

## Why This Matters

OSINT practitioners can become targets for profiling, phishing, impersonation, and social engineering. Your WhatsApp configuration should reduce unnecessary personal exposure.

## Recommended Privacy Steps

### A) Set Profile Photo visibility

1. Open **WhatsApp**.
2. Go to **Settings** > **Privacy**.
3. Select **Profile Photo**.
4. Set visibility to **My Contacts** (minimum requirement).
5. Prefer **Nobody** if you want stricter OPSEC.

### B) Set About visibility

1. In **Settings** > **Privacy**, select **About**.
2. Set visibility to **My Contacts** (minimum requirement).
3. Avoid posting sensitive descriptions (e.g., workplace, daily routine, personal identifiers).

## Additional Hardening

- **Last Seen & Online**: limit to contacts.
- **Status**: share with trusted contacts only.
- **Groups**: restrict who can add you directly.
- **Two-Step Verification**: enable PIN protection.
- **Device Security**: enable screen lock/biometric authentication.

## Operational Guidance

- Use a professional nickname aligned with community norms.
- Do not share confidential case details or non-public personal data.
- Report suspicious direct messages to moderators.

Completion of these steps is part of MOC onboarding readiness.
