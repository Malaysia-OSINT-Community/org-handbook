# Community Engagement Schedule

MOC uses a structured weekly cadence to build practical OSINT capability and peer learning consistency.

## Weekly Activities (Subject to Changes)

### Tuesday Target (Geolocation Challenge)

- Focus: image/video geolocation and environmental clue analysis.
- Format: one curated challenge per week.
- Expected Output: reasoning chain, supporting evidence, and confidence level.
- Learning Goal: improve structured analysis and source validation.

### Tool-Tip Thursday (OSINT Tool Breakdown)

- Focus: one specific OSINT tool, workflow, or technique each week.
- Format: short technical walkthrough + use-case discussion.
- Expected Output: tool limitations, verification strategy, and ethical constraints.
- Learning Goal: practical competency with reproducible methodology.

## Participation Standard

- Contribute respectfully and cite sources where possible.
- Ask technical questions clearly with context.
- Prioritize quality of analysis over speed.

## Moderation Note

All engagement remains subject to [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) and [DISCLAIMER.md](../DISCLAIMER.md).
